# Portfolio Optimization Using Modern Portfolio Theory

## Project Overview

This project focuses on analyzing financial assets and constructing an optimized investment portfolio using historical market data.

The project combines:

- Time-series forecasting
- Risk-return analysis
- Portfolio diversification
- Modern Portfolio Theory optimization

## Objectives

The main objectives are:

1. Analyze historical stock prices.
2. Forecast Tesla stock prices using ARIMA.
3. Evaluate risk and return characteristics.
4. Analyze relationships between assets.
5. Construct an optimized portfolio using the Sharpe Ratio.

## Assets Used

The portfolio consists of:

| Asset | Description |
|---|---|
| TSLA | Tesla Inc. stock |
| SPY | S&P 500 ETF |
| BND | Total Bond Market ETF |

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Statsmodels
- Yahoo Finance API
- Jupyter Notebook

## Project Workflow

### 1. Data Collection

Historical financial data was collected using Yahoo Finance.

### 2. Exploratory Data Analysis

The project analyzed:

- Historical price movement
- Daily returns
- Volatility
- Correlation between assets

### 3. Time Series Forecasting

Tesla stock prices were analyzed using:

- Augmented Dickey-Fuller (ADF) test
- ARIMA forecasting model

### 4. Portfolio Optimization

Modern Portfolio Theory was applied by:

- Generating multiple portfolios
- Calculating expected returns
- Measuring portfolio risk
- Computing Sharpe ratios
- Identifying the optimal portfolio

## Results

The project demonstrated:

- Tesla has higher return potential but higher volatility.
- Bonds provide diversification benefits.
- Combining different assets improves risk-adjusted performance.

## Future Improvements

Future improvements include:

- Applying advanced forecasting models such as LSTM.
- Using more assets.
- Adding real-time portfolio tracking.
- Implementing automated optimization algorithms.
